# 實作卡 B — 匯率警報看板

> 預估時間：15–20 分鐘 | 難度：中等
> 涵蓋概念：Manual Trigger、HTTP Request、Code、IF、Set、Expression

---

## 情境

你計劃暑假去日本旅遊，想盯著日圓匯率。
當美元兌日圓超過 155（日圓貶值 = 換匯划算），產生「好消息」提醒；
否則產生「再等等」提醒。順便整理台幣和韓元匯率。

**目標：** 抓即時匯率 → 篩出 3 種幣別 → 判斷門檻 → 輸出提醒訊息

---

## 素材與設定

| 項目 | 值 |
|------|-----|
| API 來源 | `https://tw.rter.info/capi.php` |
| 格式 | JSON，免認證 |
| 篩選幣別 | `USDJPY`（日圓）、`USDTWD`（台幣）、`USDKRW`（韓元） |
| 判斷門檻 | 日圓匯率 > **155** = 划算 |

**API 回傳格式範例：**

```json
{
  "USDTWD": { "Exrate": 32.01, "UTC": "2026-03-28 06:00:00" },
  "USDJPY": { "Exrate": 160.25, "UTC": "2026-03-28 06:00:00" },
  "USDKRW": { "Exrate": 1511.66, "UTC": "2026-03-28 06:00:00" },
  "USDEUR": { "Exrate": 0.8685, "UTC": "2026-03-28 06:00:00" },
  ...其他 200+ 種幣別
}
```

---

## 流程圖

```
Manual Trigger
      │
      ▼
HTTP Request（GET 匯率 JSON）
      │
      ▼
Code（從 200+ 幣別篩出 JPY / TWD / KRW）
      │
      ▼
IF（日圓 > 155？）
  ├─ true  ──▶ Set（好消息通知）
  └─ false ──▶ Set（再等等通知）
```

---

## Step 1：建立 Manual Trigger

1. 在 n8n 畫布按 **+** 新增節點
2. 搜尋 `Manual Trigger`，加入畫布
3. 不需要任何設定

---

## Step 2：加入 HTTP Request 節點

1. 從 Manual Trigger 拉線，新增 `HTTP Request`
2. 設定如下：

| 欄位 | 值 |
|------|-----|
| Method | `GET`（預設） |
| URL | `https://tw.rter.info/capi.php` |

3. 其他設定保持預設
4. 按 **Test step** 測試 → 應該看到一個超大的 JSON 物件，有 200+ 個幣別

**觀察重點：** 找到 `USDJPY`、`USDTWD`、`USDKRW`，看看 `Exrate` 值是多少

---

## Step 3：加入 Code 節點（篩選幣別）

1. 從 HTTP Request 拉線，新增 `Code`
2. Language 選 **JavaScript**
3. 貼上以下程式碼：

```javascript
// Step 3: Extract 3 currencies from 200+ pairs
const raw = $input.first().json;

// Handle both cases: n8n auto-parsed JSON or string in data field
const data = (typeof raw.data === 'string') ? JSON.parse(raw.data) : raw;

return [{
  json: {
    jpy_rate: data.USDJPY.Exrate,
    jpy_label: '1 USD = ¥' + data.USDJPY.Exrate,
    twd_rate: data.USDTWD.Exrate,
    twd_label: '1 USD = NT$' + data.USDTWD.Exrate,
    krw_rate: data.USDKRW.Exrate,
    krw_label: '1 USD = ₩' + data.USDKRW.Exrate,
    updated: data.USDJPY.UTC
  }
}];
```

4. 按 **Test step** → 應該看到 1 筆資料，包含 7 個欄位

**理解重點：**
- `typeof raw.data === 'string'` 這行是防呆：有時 API 回傳的是字串，需要 `JSON.parse` 轉換
- `data.USDJPY.Exrate` = 從大物件裡取值（L02 Expression 概念）
- 我們同時做了「篩選」（只留 3 種）和「轉換」（加上 label 格式化）

---

## Step 4：加入 IF 節點（判斷門檻）

1. 從 Code 拉線，新增 `IF`
2. 設定條件：

| 欄位 | 值 |
|------|-----|
| Value 1 (左邊) | `{{ $json.jpy_rate }}` |
| Operation | `is greater than` (大於) |
| Value 2 (右邊) | `155` |

3. 按 **Test step** → 資料會走 true 或 false（取決於當前日圓匯率）

**知識點：** 日圓匯率數字越大 = 日圓越便宜 = 換匯越划算
- 160 = 用 1 美元可以換 160 日圓（便宜）
- 140 = 用 1 美元只能換 140 日圓（貴）

---

## Step 5a：加入 Set 節點 — 好消息（true 分支）

1. 從 IF 的 **true** 輸出拉線，新增 `Set`
2. 命名為 `Set — 好消息通知`
3. 切換到 **Manual Mapping** 模式
4. 新增以下欄位：

| 欄位名 | 類型 | 值 |
|--------|------|-----|
| `verdict` | String | `好消息！日圓便宜了，可以換匯！` |
| `jpy` | String | `{{ $json.jpy_label }}` |
| `twd` | String | `{{ $json.twd_label }}` |
| `krw` | String | `{{ $json.krw_label }}` |
| `message` | String | 見下方 |

**message 欄位的值（完整貼上）：**

```
旅遊匯率看板 ({{ $json.updated }})
---
日圓：{{ $json.jpy_label }}
台幣：{{ $json.twd_label }}
韓元：{{ $json.krw_label }}
---
判斷：日圓超過 155，現在換匯划算！
```

5. **Include Other Fields** 設為 `false`

---

## Step 5b：加入 Set 節點 — 再等等（false 分支）

1. 從 IF 的 **false** 輸出拉線，新增另一個 `Set`
2. 命名為 `Set — 再等等通知`
3. 同樣切換到 **Manual Mapping**，新增以下欄位：

| 欄位名 | 類型 | 值 |
|--------|------|-----|
| `verdict` | String | `再等等，日圓還沒到甜蜜點` |
| `jpy` | String | `{{ $json.jpy_label }}` |
| `twd` | String | `{{ $json.twd_label }}` |
| `krw` | String | `{{ $json.krw_label }}` |
| `message` | String | 見下方 |

**message 欄位的值（完整貼上）：**

```
旅遊匯率看板 ({{ $json.updated }})
---
日圓：{{ $json.jpy_label }}
台幣：{{ $json.twd_label }}
韓元：{{ $json.krw_label }}
---
判斷：日圓未超過 155，建議再觀望。
```

5. **Include Other Fields** 設為 `false`

## 延伸挑戰

完成太快？試試這些：

1. **三段判斷：** 把 IF 換成 `Switch` 節點，根據匯率區間輸出不同訊息：
   - < 145 →「太貴了，不建議換」
   - 145–155 →「普通，可以小量換」
   - \> 155 →「便宜，大量換匯！」

2. **更多幣別：** 在 Code 節點多加 EUR（歐元）、THB（泰銖）、GBP（英鎊），做成完整旅遊看板

3. **模擬通知：** 在最終 Set 後面再加兩個 Set 節點（用 Fan-out），模擬「同時通知 LINE + Email」

4. **自動執行：** 把 Manual Trigger 換成 `Schedule Trigger`，設定每小時執行一次

## 常見卡關 Q&A

**Q：HTTP Request 回來是空的或報錯？**
A：確認 URL 是 `https://tw.rter.info/capi.php`。這個 API 偶爾會慢，等幾秒再試

**Q：Code 節點報 `Cannot read properties of undefined`？**
A：表示取不到值。確認拼寫是 `USDJPY`（全大寫），不是 `UsdJpy`

**Q：IF 節點條件設定後還是 0 筆？**
A：確認 Value 1 是用 Expression 模式（點欄位右邊的 `{ }` 切換），不是直接打文字

**Q：Set 的 message 顯示 `{{ $json.jpy_label }}` 而不是實際數字？**
A：欄位的值要用 Expression 模式。點欄位右邊的 `{ }` 圖示切換，或確認值的開頭有 `=` 符號
