### Slide 2-6｜實作導航 — Credentials 設定

**類型：** 實作導航頁

**標題：** 動手時間：設定 Notion + Google Drive 授權

**Notion API 設定：**
1. 到 Notion → Settings → Integrations → 建立新的 Integration
2. 複製 Internal Integration Token
3. 回到 n8n → Credentials → 新增 Notion API → 貼上 Token
4. 到 Notion 知識庫頁面 → 點「...」→ Add connections → 選你的 Integration

**Google Drive API 設定：**
1. 到 Google Cloud Console → 建立專案 → 啟用 Drive API
2. 建立 OAuth 2.0 Credentials
3. 回到 n8n → Credentials → 新增 Google Drive OAuth2 → 完成授權

**踩坑提醒：**
- Notion Integration 要記得在頁面上「Connect」，不然 n8n 讀不到
- Google OAuth 要加入測試使用者（你自己的 Gmail）

**預估時間：** 15 分鐘

> **口白提示：** 「卡住的舉手，我來幫你看。這一步過了，後面就順了。」

### Slide 3-6｜去重策略

**類型：** 概念頁

**標題：** 為什麼需要去重？

**內容（對比圖）：**

| 沒有去重 | 有去重 |
|---------|--------|
| 同一份文件改了 3 次 | 同一份文件只保留最新版 |
| Pinecone 存了 3 份重複內容 | 用 doc_id + updated_at 判斷 |
| 搜尋結果重複出現 | 搜尋結果乾淨精準 |
| 像 LINE 相簿裡同一張照片存三次 | 每張照片只有一份 |

**去重邏輯：**
```
如果 doc_id 已存在 且 updated_at 沒變 → 跳過
如果 doc_id 已存在 且 updated_at 更新 → 覆蓋
如果 doc_id 不存在 → 新增
```

> **口白提示：** 「去重不做也能動，但搜尋結果會很亂。這是系統品質的關鍵。」

```
❌ 重複 30 次                ✅ 自動重複 ∞ 次
```

**底部金句：**
> 流程本身就是問題。不是把爛流程做快，是把流程重新設計。

> **口白提示：** 「很多人會說：我想讓現在的流程更快。但正確的問法是：這個流程還需要存在嗎？」

### Slide 5-5｜三種商業模式

**類型：** 框架頁

**標題：** 這個技能怎麼變現？

**內容（三欄對比）：**

| 模式 | 客製化建置 | SaaS 訂閱制 | 顧問 / 培訓服務 |
|------|-----------|-------------|---------------|
| **怎麼賺** | 幫客戶建置一套系統，收一次性費用 | 做成產品，客戶按月付費 | 教別人怎麼做，收培訓費 |
| **定價參考** | 5-30 萬 / 案 | 2,000-10,000 / 月 | 1-5 萬 / 場 |
| **優點** | 單價高、快速獲利 | 被動收入、可規模化 | 門檻低、建立個人品牌 |
| **挑戰** | 客製化耗時、難規模化 | 需要產品化思維 | 需要教學能力 |
| **適合誰** | 接案工程師、工作室 | 有產品思維的團隊 | 有教學熱情的人 |

> **口白提示：** 「你今天學會的東西，已經可以接案了。很多公司花幾十萬請人做的事，就是你今天做的這套系統。」
