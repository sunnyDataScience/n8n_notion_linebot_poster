## 附錄：簡報設計建議

### 視覺風格
- **主色調：** 深藍 + 亮綠（科技感 + 自動化意象）
- **字體：** 標題用粗體無襯線（如 Noto Sans TC Bold），內文用 Regular
- **每頁文字量：** 不超過 50 個中文字（圖表除外）
- **配圖風格：** 扁平化圖示、線條式架構圖、真實截圖

### 頁面類型對應設計
| 頁面類型 | 設計重點 |
|---------|---------|
| 封面 / 單元封面 | 大標題 + 副標 + 金句，背景深色 |
| 概念頁 | 一個核心概念 + 圖示或比喻，留白多 |
| 架構頁 | 流程圖為主，文字為輔 |
| 對比頁 | 雙欄或表格，顏色區分兩邊 |
| 實作導航頁 | 步驟清單 + 預期結果 + 預估時間，底色用淺綠 |
| 回顧頁 | 核取清單風格，打勾的成就感 |
| 轉場頁 | 大字金句，視覺衝擊 |
