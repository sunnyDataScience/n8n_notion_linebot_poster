### Slide 2-2｜n8n 是什麼

**類型：** 概念頁

**標題：** n8n = 不同 App 之間的膠水

**內容：**

- n8n 的名字：n + (odeSautomatio) 中間 8 個字母 + n
- 不是 AI，但能串接 AI
- 無程式碼 / 低程式碼，拖拉節點就能完成任務

**配圖概念：**

[Notion]      ──→ │ 膠水  │ ──→ [LINE Bot]
                   └──────┘

**底部：**

### Slide 2-6｜實作導航 — Credentials 設定

**類型：** 實作導航頁

**標題：** 動手時間：設定 Notion + Google Drive 授權

**Notion API 設定：**
1. 到 Notion → Settings → Integrations → 建立新的 Integration
2. 複製 Internal Integration Token
3. 回到 n8n → Credentials → 新增 Notion API → 貼上 Token
4. 到 Notion 知識庫頁面 → 點「...」→ Add connections → 選你的 Integration

**Google Drive API 設定：**
1. 到 Google Cloud Console → 建立專案 → 啟用 Drive API
2. 建立 OAuth 2.0 Credentials
3. 回到 n8n → Credentials → 新增 Google Drive OAuth2 → 完成授權

**踩坑提醒：**
- Notion Integration 要記得在頁面上「Connect」，不然 n8n 讀不到
- Google OAuth 要加入測試使用者（你自己的 Gmail）

**預估時間：** 15 分鐘

> **口白提示：** 「卡住的舉手，我來幫你看。這一步過了，後面就順了。」

### Slide 2-8｜實作導航 — 第一條工作流

**類型：** 實作導航頁

**標題：** 動手時間：你的第一條工作流

**目標：** 在 Notion 打字 → n8n 自動偵測到並處理

**節點序列：**
```
[Notion Trigger] → [Set 節點] → [輸出確認訊息]
  偵測新資料        整理欄位        確認成功
```

**步驟：**
1. 拉一個 Notion Trigger 節點，選擇你的知識庫 DB
2. 拉一個 Set 節點，設定要保留的欄位（標題、內容）
3. 按下 Test Workflow
4. 去 Notion 新增一筆資料
5. 回到 n8n 看有沒有觸發

**預期結果：** 你在 Notion 打字 → n8n 那邊自動跑起來了

**預估時間：** 12 分鐘

> **口白提示：** 「這是你人生中第一條自動化工作流。做完的人先感受一下這個感覺 — 你在 Notion 打字，n8n 那邊就動了。」
