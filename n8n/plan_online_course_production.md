# 線上課程製作藍圖：n8n 自動化工作流實戰 — 打造你的 LINE AI 助理

**總體設計原則：**

- **微課時 (Micro-learning):** 每個影片課時控制在 5-15 分鐘，專注講透一個核心知識點。
- **混合形式 (Mixed-format):** 交錯使用講師畫面、簡報、螢幕錄製、動態圖示等形式，維持學習新鮮感。
- **實踐導向 (Action-oriented):** 每個單元結束後都伴隨明確的實作任務，引導學員完成最終交付物（LINE AI 助理 + 自動化知識庫）。
- **零基礎友善 (Beginner-first):** 全程以拖拉節點操作呈現，不假設任何程式經驗，螢幕錄製搭配逐步引導。

### 錄製環境

- 安靜空間（無回音、無背景噪音）
- 乾淨背景（書架/植物/淺色牆面/綠幕）
- 螢幕解析度設定為 1920x1080
- n8n 畫布縮放至適當比例，確保節點文字清晰可讀
- 瀏覽器縮放 125-150%（確保 Notion / LINE Developers 介面清晰）
- 建議使用雙螢幕：一個螢幕操作 n8n，另一個螢幕顯示 Notion / LINE 畫面

### n8n 錄製專屬注意事項

- n8n 畫布背景建議使用淺色主題，避免深色模式影響螢幕錄製可讀性
- 錄製前清除 n8n 執行紀錄，避免敏感資料洩漏
- 所有 Demo 用的 API Key 使用獨立測試帳號，不要暴露正式帳號 Credentials
- LINE Bot 測試時使用專用測試群組，避免錄到私人對話
- Pinecone Index 使用課程專用 namespace，錄製後可統一清除
